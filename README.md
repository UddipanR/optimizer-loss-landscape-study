# Optimizer Loss Landscape Study

Comparative study of SGD, Adam, AdamW, and Lion optimizers using loss 
landscape visualization, Hessian-based sharpness analysis, and training 
trajectory analysis, to examine whether flatter minima actually 
correspond to better generalization.

Status: Work in progress (40-day research project)

## Structure
- `code/` — training and analysis scripts
- `configs/` — run configurations
- `logs/` — training metrics (loss/accuracy per epoch)
- `figures/` — final plots and visualizations
